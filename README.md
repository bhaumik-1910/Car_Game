# 🚗 Car Game

Car Game is a simple **HTML, CSS, and JavaScript** browser game where a player controls a car and avoids obstacles.  
This project demonstrates basic game logic, DOM manipulation, event handling, and simple animations.

---

## 🌟 Features

- 🚘 Player-controlled car movement  
- 🎯 Obstacle generation  
- 🕹️ Keyboard controls  
- 🧠 Score tracking  
- 📱 Responsive & fun UI

---

## 🛠 Tech Stack

- **HTML5**
- **CSS3**
- **JavaScript (ES6+)**
- **VS Code Live Server**


---

## ⚙️ Getting Started

### 1️⃣ Clone the repository
```bash
git clone https://github.com/bhaumik-1910/Car_Game.git
cd Car_Game
```


###2️⃣ Run the game
Open index.html directly in your browser
```bash
Right Click on index.html → Open with Live Server
```
